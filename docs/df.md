# df

opsxcli df — 显示文件系统磁盘空间使用情况

## 用法

`opsxcli df [args...]`

## 说明

显示已挂载文件系统的磁盘空间使用情况，包括总容量、已用、可用空间和挂载点。所有参数直接转发给系统 `df` 命令。

## 选项

此命令无自定义选项，以下为系统 `df` 常用参数：

| 参数 | 说明 |
|------|------|
| `-h` | 以人类可读格式显示 |
| `-i` | 显示 inode 使用情况 |
| `-T` | 显示文件系统类型 |
| `-t TYPE` | 仅显示指定类型的文件系统 |
| `-x TYPE` | 排除指定类型的文件系统 |
| `--total` | 额外显示总计行 |

## 示例

以人类可读格式显示磁盘使用：

```bash
opsxcli df -h
```

显示 inode 使用情况：

```bash
opsxcli df -ih
```

显示文件系统类型：

```bash
opsxcli df -hT
```

仅显示 ext4 文件系统：

```bash
opsxcli df -ht ext4
```
