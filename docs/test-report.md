## 🐛 已知问题

### 1. 百度搜索响应较小 (1.5 KB)
- **现象**: 百度返回 HTML 仅 1.5 KB,可能被反爬
- **影响**: 低 - 仍能获取搜索 URL
- **解决方案**: 增加更真实的浏览器 Headers

### 2. HTML 内容未解析
- **现象**: 返回完整 HTML,消耗大量 tokens
- **影响**: 高 - Token 浪费严重
- **解决方案**: 实施 Token 优化策略 (已文档化)

### 3. 缺少缓存机制
- **现象**: 相同搜索重复执行
- **影响**: 中 - 浪费资源和 tokens
- **解决方案**: 添加搜索缓存 (24h TTL)
