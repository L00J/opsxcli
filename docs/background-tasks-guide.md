# opsxcli 后台任务管理指南

## 快速开始

### 启用后台任务模式

```bash
# 基本用法
./opsxcli agent -i -b -p deepseek

# 完整示例(推荐)
./opsxcli agent -i -b -y -p deepseek  # 交互式 + 后台任务 + 自动批准
```

**参数说明**:
- `-i, --interactive`: 交互模式
- `-b, --background`: 启用后台任务管理
- `-y, --yes`: 自动批准所有操作
- `-p, --provider`: LLM提供商(deepseek/claude/ollama)

## 核心特性

### 1. 并发执行

- ✅ 多个任务同时运行,互不阻塞
- ✅ 每个任务有独立的 ReAct 循环
- ✅ 支持同时运行 5+ 个任务

### 2. 实时状态

- ✅ 底部状态栏显示任务数量
- ✅ 任务列表显示运行时间
- ✅ 自动更新任务状态

### 3. 任务管理

- ✅ `/tasks` - 查看所有任务
- ✅ `/switch` - 切换当前任务
- ✅ `/exit` - 退出会话

## 底部状态栏

```
⏵⏵ Task 1/3 (shift+tab to cycle) · 3 background tasks
```

**说明**:
- `Task 1/3`: 当前聚焦第1个任务,总共3个任务
- `shift+tab to cycle`: 提示切换快捷键(功能开发中)
- `3 background tasks`: 总共3个后台任务

## 任务状态

| 状态 | 说明 | 图标 |
|------|------|------|
| Running | 任务执行中 | 🔄 Running (2m 15s) |
| Completed | 任务成功完成 | ✅ Completed |
| Failed | 任务执行失败 | ❌ Failed |
| Cancelled | 任务被取消 | ⊘ Cancelled |

## 最佳实践

### 1. 合理控制任务数量

建议同时运行不超过 5 个任务,避免系统资源耗尽。

### 2. 使用 `-y` 自动批准

后台任务模式建议配合 `-y` 使用,避免需要频繁确认:

```bash
./opsxcli agent -i -b -y -p deepseek  # ✅ 推荐
```

### 3. 不使用 `-d` 调试模式

后台任务模式下不建议使用 `-d`,会产生大量调试信息:

```bash
./opsxcli agent -i -b -d -p deepseek  # ❌ 输出太多
./opsxcli agent -i -b -p deepseek     # ✅ 简洁清晰
```

### 4. 精确描述任务

提供精确的任务描述,帮助 AI 更快完成:

```bash
# ❌ 模糊
> 部署数据库

# ✅ 精确
> 部署 MySQL 8.0 到 /opt/mysql,端口 3306,root密码设为 MyPass123
```

### 5. 定期清理完成的任务

查看任务列表,了解哪些任务已完成,可以退出重新开始清空列表。

## 技术架构

### 并发模型

```
用户输入 → inputChan
    ↓
任务创建 → BackgroundTask
    ↓
goroutine 执行 → ReAct 循环
    ↓
完成通知 → taskCompleteChan
```

### 事件循环

```go
for {
    select {
    case <-ctx.Done():
        // 会话取消
    case taskID := <-taskCompleteChan:
        // 任务完成,显示结果
    case userInput := <-inputChan:
        // 用户输入,创建新任务
    }
}
```

### 任务隔离

每个任务有:
- 独立的 context
- 独立的消息历史
- 独立的工具调用历史
- 独立的输出缓冲区

## 故障排查

### 任务无法创建

**问题**: 输入后没有显示"任务已创建"

**解决**:
1. 检查输入是否为空
2. 确认已使用 `-b` 标志启用后台任务模式

### 任务卡住不执行

**问题**: 任务显示 Running 但长时间没有输出

**原因**: 可能需要用户确认操作

**解决**: 使用 `-y` 自动批准

### 任务列表为空

**问题**: 输入 `/tasks` 显示没有任务

**解决**: 先创建一个任务,然后再查看列表

## 常见问题

**Q: 可以暂停任务吗?**
A: 当前版本不支持暂停,任务会一直执行直到完成或失败。

**Q: 如何取消任务?**
A: 当前版本不支持取消单个任务,可以按 Ctrl+C 退出整个会话。

**Q: 任务完成后会自动清理吗?**
A: 任务完成后会保留在任务列表中,退出会话后清空。

**Q: 支持多少个并发任务?**
A: 理论上没有限制,但建议不超过5个以避免资源耗尽。

**Q: 任务输出会保存吗?**
A: 任务输出保存在内存中,会话结束后清空。未来版本会支持持久化。
