# uname

opsxcli uname — 显示系统信息

## 用法

`opsxcli uname [args...]`

## 说明

显示当前系统的内核名称、版本、主机名等信息。所有参数直接转发给系统 `uname` 命令，行为与原生命令一致。

## 选项

此命令无自定义选项，以下为系统 `uname` 常用参数：

| 参数 | 说明 |
|------|------|
| `-a` | 显示所有系统信息 |
| `-s` | 显示内核名称 |
| `-n` | 显示网络节点主机名 |
| `-r` | 显示内核发行版本 |
| `-v` | 显示内核版本详情 |
| `-m` | 显示硬件架构 |
| `-p` | 显示处理器类型 |
| `-o` | 显示操作系统名称 |

## 示例

显示完整系统信息：

```bash
opsxcli uname -a
```

仅显示内核名称：

```bash
opsxcli uname -s
```

显示内核版本：

```bash
opsxcli uname -r
```

显示硬件架构：

```bash
opsxcli uname -m
```
