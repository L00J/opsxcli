# 09 - 安全系统与工具注册

> 前置阅读：[06 - Agent 核心引擎设计](06-Agent核心引擎设计.md)

## 设计理念

安全系统是运维工具的生命线。opsxcli 安全系统遵循两个核心原则：

1. **默认安全**：balanced 模式下，high+ 操作需要确认，覆盖 95% 日常运维
2. **可审计**：每次工具调用都有完整记录，事后可追溯

工具注册系统遵循**工具化思维**：万物皆 Tool，实现接口即可扩展。

## Part 1: 安全系统 (agent/safety)

### 架构总览

```
┌────────────────────────────────────────────┐
│              Safety Controller              │
│                                            │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │ Risk评估  │  │ 确认机制  │  │ 审计日志  │ │
│  │ risk.go  │  │controller│  │ audit.go │ │
│  └──────────┘  └──────────┘  └──────────┘ │
│                                            │
│  Safety Modes:                             │
│  strict → medium+ 确认                     │
│  balanced → high+ 确认（默认）              │
│  permissive → critical 仅确认              │
└────────────────────────────────────────────┘
```

### Controller 结构体

```go
// internal/agent/safety/controller.go

type Controller struct {
    mode        SafetyMode        // 当前安全模式
    autoApprove bool              // 自动批准（仅测试用）
    reader      *bufio.Reader     // 标准输入读取（用户确认）
    history     []ExecutionRecord // 执行历史（上限 1000）
    auditLog    *AuditLogWriter   // 审计日志写入器
    confirmFn   ConfirmFunc       // 自定义审批函数（可选）
}
```

### 三级安全模式

| 模式 | 需要确认的等级 | 适用场景 |
|------|---------------|----------|
| `strict` | medium 及以上 | 生产环境、新手操作 |
| `balanced` (默认) | high 及以上 | 日常运维 |
| `permissive` | 仅 critical | 测试环境、自动化脚本 |

### 五级风险评估

```go
// internal/agent/tools/registry.go

const (
    RiskSafe     RiskLevel = iota // 0 - 只读（cat, grep, df, ps）
    RiskLow                       // 1 - 低风险（mkdir, touch）
    RiskMedium                    // 2 - 中风险（chmod, 文件修改）
    RiskHigh                      // 3 - 高风险（ssh_execute, 服务控制）
    RiskCritical                  // 4 - 危险（rm -rf, mkfs, dd, 数据删除）
)
```

### 危险命令黑名单

```go
// internal/agent/safety/risk.go

var DangerousCommands = []string{
    // 文件系统毁灭性操作
    "rm -rf /", "rm -rf /*", "rm -rf /bin", "rm -rf /boot", ...
    
    // 磁盘格式化
    "mkfs", "mkfs.ext", "mkfs.xfs", "mkfs.btrfs", ...
    
    // 磁盘覆写
    "dd if=/dev/zero", "dd if=/dev/random", ...
    
    // Fork bomb
    ":(){ :|:& };:", ...
    
    // 设备重定向
    "> /dev/sda", "> /dev/sdb", ...
    
    // 权限破坏
    "chmod -R 000 /", "chmod -R 777 /", ...
}
```

### 命令分类

```go
var ReadOnlyCommands = []string{...}     // 只读命令（Safe）
var ModificationCommands = []string{...} // 修改命令（Medium）
var HighRiskCommands = []string{...}     // 高危命令（High/Critical）
```

### AssessBashRisk() 动态评估

根据命令内容动态评估风险等级，不仅看命令名，还看参数：

```go
func AssessBashRisk(cmd string) tools.RiskLevel
```

评估逻辑：
1. 精确匹配黑名单 → Critical
2. 模式匹配（通配符）→ High
3. 命令分类查表 → 对应等级
4. 默认 → Safe

### ExecutionRecord 审计记录

```go
type ExecutionRecord struct {
    ToolName  string                 // 工具名
    Args      map[string]interface{} // 调用参数
    RiskLevel tools.RiskLevel        // 风险等级
    Approved  bool                   // 是否批准
    Executed  bool                   // 是否执行
    Success   bool                   // 执行结果
    Error     string                 // 错误信息
    Timestamp time.Time              // 时间戳
    SessionID string                 // 会话 ID
    EventType string                 // check / execute
}
```

**防内存泄漏**：`maxHistorySize = 1000`，超出时 FIFO 淘汰。

### AuditLogWriter

持久化审计日志到 `~/.opsxcli/audit/audit.log`：

```
2026-04-21T14:30:00 [CHECK]  ssh_execute risk=high approved=true
2026-04-21T14:30:01 [EXEC]   ssh_execute success=true duration=1.2s
```

## Part 2: 工具注册系统 (agent/tools)

### 架构总览

```
┌─────────────────────────────────────────────────┐
│                   Registry                       │
│         (线程安全 map[string]Tool)                │
│                                                  │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │local_bash│ │ssh_exec  │ │scp_transfer      │ │
│  │ RiskHigh │ │ RiskHigh │ │ RiskMedium       │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │file_read │ │file_srch │ │analyze_output    │ │
│  │ RiskSafe │ │ RiskSafe │ │ RiskSafe         │ │
│  └──────────┘ └──────────┘ └──────────────────┘ │
│  ┌──────────────────────────────────────────────┐│
│  │ SSH Pool: 连接复用、空闲超时、自动清理         ││
│  └──────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘
```

### Tool 接口

```go
// internal/agent/tools/registry.go

type Tool interface {
    Name() string                       // 工具名称
    Description() string                // 工具描述（给 LLM 看）
    Parameters() map[string]interface{} // JSON Schema 参数定义
    RiskLevel() RiskLevel               // 静态风险等级
    Execute(ctx context.Context, args map[string]interface{}) (*Result, error)
}
```

**设计哲学**：接口最小化，5 个方法覆盖完整生命周期。

### Closer 接口

```go
type Closer interface {
    Close() error
}
```

支持资源释放的工具（如 SSH 连接池）可实现此接口，`Registry.Close()` 自动调用。

### Registry 注册中心

```go
type Registry struct {
    tools map[string]Tool
    mu    sync.RWMutex  // 读写锁，支持并发注册和查询
}
```

核心方法：

| 方法 | 说明 |
|------|------|
| `NewRegistry()` | 创建空注册中心 |
| `Register(tool)` | 注册工具（线程安全） |
| `Get(name) Tool` | 按名称获取工具 |
| `List() []Tool` | 列出所有工具 |
| `Close()` | 关闭所有实现 Closer 的工具 |

### Result 结构体

```go
type Result struct {
    Success bool   `json:"success"`          // 是否成功
    Output  string `json:"output"`            // 输出内容
    Error   string `json:"error,omitempty"`   // 错误信息
    Summary string `json:"summary,omitempty"` // 结果摘要
}
```

### 已注册工具一览

| 工具 | 风险等级 | 功能 | 关键特性 |
|------|----------|------|----------|
| `local_bash` | High | 本地命令执行 | 超时控制、输出截断 |
| `ssh_execute` | High | 远程命令执行 | SSH 连接池、多主机 |
| `scp_transfer` | Medium | 文件传输 | 进度显示、断点续传 |
| `file_read` | Safe | 文件读取 | 行号定位、范围读取 |
| `file_search` | Safe | 文件搜索 | 正则匹配、上下文行 |
| `analyze_output` | Safe | 输出分析 | 格式化、关键信息提取 |

### SSH 连接池

```go
// internal/agent/tools/ssh_pool.go

type SSHConnKey struct {
    Host     string
    Port     int
    User     string
    KeyPath  string
}

type SSHPool struct {
    connections map[SSHConnKey]*ssh.Client
    mu          sync.RWMutex
    maxSize     int           // 最大连接数
    idleTimeout time.Duration // 空闲超时
}
```

特性：
- 连接复用：相同 (Host, Port, User, KeyPath) 共享连接
- 空闲超时：自动清理长时间未使用的连接
- 线程安全：RWMutex 保护连接池

## 扩展指南

### 添加新工具

```go
// 1. 实现 Tool 接口
type MyTool struct{}

func (t *MyTool) Name() string { return "my_tool" }
func (t *MyTool) Description() string { return "我的自定义工具" }
func (t *MyTool) Parameters() map[string]interface{} {
    return map[string]interface{}{
        "type": "object",
        "properties": map[string]interface{}{
            "target": map[string]interface{}{
                "type":        "string",
                "description": "目标地址",
            },
        },
        "required": []string{"target"},
    }
}
func (t *MyTool) RiskLevel() tools.RiskLevel { return tools.RiskMedium }
func (t *MyTool) Execute(ctx context.Context, args map[string]interface{}) (*tools.Result, error) {
    // 实现逻辑
    return &tools.Result{Success: true, Output: "done"}, nil
}

// 2. 注册到 Registry
registry := tools.NewRegistry()
registry.Register(&MyTool{})
```

### 添加自定义安全规则

1. 在 `risk.go` 中扩展 `DangerousCommands` 或 `HighRiskCommands`
2. 在 `audit.go` 中调整 `IsDangerousCommand()` 逻辑
3. 测试新增规则是否正确拦截

### 自定义审批函数

```go
ctl := safety.NewController(safety.SafetyModeBalanced)
ctl.SetConfirmFn(func(toolName string, args map[string]interface{}, risk tools.RiskLevel) (bool, error) {
    // 自定义审批逻辑（如对接企业审批系统）
    return true, nil
})
```

## 常见陷阱

| 陷阱 | 解决方案 |
|------|----------|
| 忘记设置 RiskLevel 导致误判 | 默认 RiskSafe，高危操作必须显式声明 |
| SSH 连接池泄漏 | 实现 Closer 接口，Registry.Close() 自动清理 |
| history 切片无限增长 | maxHistorySize=1000 FIFO 淘汰 |
| 危险命令只看前缀匹配 | AssessBashRisk 同时做精确匹配和模式匹配 |
| 工具 Execute 无超时 | Config.ToolTimeout=60s 兜底 |
