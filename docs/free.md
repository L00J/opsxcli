# free

opsxcli free — 显示系统内存使用情况

## 用法

`opsxcli free [args...]`

## 说明

显示系统的物理内存和交换分区的使用情况，包括总量、已用、空闲、缓存等信息。所有参数直接转发给系统 `free` 命令。

## 选项

此命令无自定义选项，以下为系统 `free` 常用参数：

| 参数 | 说明 |
|------|------|
| `-h` | 以人类可读格式显示（自动选择合适的单位） |
| `-b` | 以字节为单位显示 |
| `-k` | 以 KB 为单位显示 |
| `-m` | 以 MB 为单位显示 |
| `-g` | 以 GB 为单位显示 |
| `-t` | 额外显示总计行 |
| `-s N` | 每 N 秒刷新一次 |
| `-c N` | 刷新 N 次后退出 |

## 示例

以人类可读格式显示内存信息：

```bash
opsxcli free -h
```

以 MB 为单位显示：

```bash
opsxcli free -m
```

每 2 秒持续监控内存使用：

```bash
opsxcli free -h -s 2
```

显示包含总计行：

```bash
opsxcli free -ht
```
